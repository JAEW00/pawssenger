# Pawssenger

반려견과 함께 차를 타는 보호자를 위한 차량 인포테인먼트 앱입니다. 차량 데이터로 반려견이 느끼는 이동 환경을 점수로 보여 주고, 출발 전 안전 확인부터 주행 중 안내, 휴식 장소 추천, 이동 기록, 잠시 내릴 때의 실내 온도 관리까지 한 화면 흐름으로 제공합니다.

현대자동차그룹 Pleos Connect(Android Automotive OS) 환경을 대상으로 만들었습니다.

## 주요 기능

| 화면 | 내용 |
|---|---|
| **메인 대시보드** | 실시간 펫 편안함 지수(0~100점)와 안정·주의·위험 단계, 실내 온도·차량 속도·주행 진동·급가속/급제동 현황, 최근 1~12시간 지수 추이 |
| **펫 세이프 대시보드** | 이동장·하네스 확인(보호자가 눌러서 확인), 창문·도어 상태(차량 연동), 실내 온도와 소음 |
| **주행 케어** | 주행 중 지수 변화 그래프, 급가속·급제동·급회전 이벤트 목록(최근 10분 요약), 반려견을 위한 주행 안내 |
| **휴식 추천** | 내 주변 또는 목적지 주변의 반려동물 동반 장소(전국 993곳)를 지도와 목록으로 보여 주고 내비게이션 목적지·경유지로 전송 |
| **이동 리포트** | 주·월·전체 기간별 평균 지수 그래프, 직전 기간 비교, 주행 이력과 주행별 상세 |
| **주정차 케어 모드** | 주차(P) 중 공조를 켜서 목표 온도를 유지하고, 차량 밖에서도 읽히는 안내 화면과 반려견용 영상·사운드를 재생. 배터리 잔량에 따라 단계적으로 절전 |
| **설정** | 반려견 프로필, 실내 온도 표시 방식(실제/시연), 예시 기록, 차량 연동 상태 진단 |

## 펫 편안함 지수

네 항목의 가중 평균에서 펫 세이프 감점을 뺀 값입니다.

| 항목 | 가중치 | 기준 |
|---|---|---|
| 급가속·급제동 | 0.30 | 종가속도 ±3.0 m/s² 이상, 최근 10분 횟수 |
| 급회전·진동 | 0.25 | 횡가속도 4.5 m/s² 이상이 0.5초 지속 |
| 실내 환경 | 0.20 | 실내 온도 18~26℃ 안정, 실내 소음 |
| 주행 안정성 | 0.25 | 속도 100km/h 이하 안정, 130km/h 이상 위험 |

- 단계: 안정 90점 이상, 주의 71~89점, 위험 70점 이하
- 펫 세이프 항목이 주의면 6점, 위험이면 18점을 뺍니다.
- 가속도 센서 값은 차량에서 받을 수 없어 속도(10Hz)와 핸들 각도로 계산합니다.
- 실내 소음은 센서가 없어 속도로 추정한 값입니다.

## 차량 연동

| 데이터 | 출처 |
|---|---|
| 차량 속도 | AAOS `android.car` (`PERF_VEHICLE_SPEED`) |
| 조향각, 기어, 브레이크, 창문, 도어, 좌석, 공조, 배터리 | Pleos Vehicle SDK 2.3.2 |
| 공조 전원·설정 온도 제어 | Pleos Vehicle SDK (주정차 케어 모드) |
| 현재 위치 | Pleos FusedLocation 1.1.3 |
| 목적지·경유지 전송, 장소 검색 화면 | Pleos NaviHelper 3.0.5 |

항목마다 지원 여부가 차종과 에뮬레이터에 따라 다르므로, 연동 실패는 앱을 멈추지 않고 설정 화면의 "차량 연동 상태"에 표시합니다.

## 기술 구성

- Kotlin 2.0.21, Jetpack Compose (BOM 2024.10.01), 단일 Activity
- Android Gradle Plugin 8.7.3, Gradle 8.11.1, JDK 17
- Room 2.6.1 (프로필, 주행 기록, 지수 시계열)
- MapLibre Android SDK 12.3.1 + OpenFreeMap 지도 타일 (API 키 불필요)
- minSdk 28, targetSdk 34

## 프로젝트 구조

```
app/src/main/java/com/pawssenger/app/
├─ vehicle/      차량 연동 (VehicleGateway: 속도, 조향, 공조, 배터리, 위치, 내비)
├─ analysis/     가속도 계산과 급가속·급제동·급회전 감지
├─ comfort/      펫 편안함 지수 계산
├─ drive/        주행(트립) 자동 시작·종료·저장
├─ dashboard/    화면 상태 생성, 시연용 실내 온도
├─ stay/         주정차 케어 모드
├─ data/         저장소, Room DB, 장소 검색, 리포트 통계
└─ ui/           화면 (main, drive, rest, report, stay, settings, components)
app/src/main/assets/places.json   반려동물 동반 장소 데이터
app/src/main/res/raw/             주정차 케어 모드용 영상·사운드
tools/build_places.py             장소 데이터 생성 스크립트
docs/data/                        장소 원본 데이터
```

## 빌드와 실행

개발 환경 설정(Android Studio, Pleos Connect 에뮬레이터 이미지)은 [README_SETUP.md](README_SETUP.md)를 참고하세요.

```bash
# JDK 17 필요
./gradlew :app:testDebugUnitTest     # 단위 테스트
./gradlew :app:assembleDebug         # 디버그 빌드
./gradlew :app:assembleRelease       # 릴리스 빌드 → app/build/outputs/apk/release/
```

에뮬레이터에 설치하고 실행합니다.

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
adb shell am start -n com.pawssenger.app/.ui.MainActivity
```

처음 실행하면 기어가 P일 때 차량 속도와 위치 권한을 요청합니다. 이동 리포트를 바로 살펴보려면 설정의 "예시 기록 넣기"를 누르세요.

## 알아 둘 점

- **주정차 케어 모드는 차량이 켜져 있는 동안 동작합니다.** 보호자가 내린 뒤에도 차량 전원과 공조를 유지하는 것은 차량 쪽 기능(유틸리티 모드 등)에 달려 있고, 앱이 제어할 수 없습니다.
- **실내 온도 "시연" 모드**는 에뮬레이터가 실내 온도 값을 바꾸지 않기 때문에 넣은 것입니다. 설정 온도를 향해 서서히 변하는 값을 만들어 보여 주며, 실제 측정값이 아닙니다. 실차에서는 "실제"로 두면 됩니다.
- 이동장·하네스는 차량에 센서가 없어 보호자가 출발 전에 눌러서 확인합니다.
- 지도 타일은 인터넷이 필요합니다. 연결이 안 되면 약식 지도로 대신 표시하고, 장소 목록은 내장 데이터로 동작합니다.
